Needed Match — live football player (its own Netlify site, separate from thiswasneeded.info)

Netlify, once:
  Add new site > Import an existing project > GitHub > nburland94/TWNMain
  Branch: needed-match   Base directory: NeededMatch   Build command: (empty)   Publish: NeededMatch
  Site configuration > Environment variables > ADMIN_KEY = your edit password
  Deploy. Then open the site, press Edit, enter the password, add channels.
Channels are stored in Netlify Blobs on the site, not in this repo.
