    Set up, once.

    Four steps, about ten minutes. After that it's one tap from anywhere — even the side button.

    On your Mac

    In Needed Tools, Home › Your phone › turn on Needed Vault. It makes the folder iCloud Drive › Shortcuts › Needed Vault, with every project's Stills, GIFs and Motion in it, and keeps it matching each time you press Sync.

    The “Save to Needed Vault” Shortcut

    Open the Shortcuts app › +. Name it exactly Save to Needed Vault.

    Show every action
    1. Tap ⓘ: turn on Show in Share Sheet. Receive Images, Media, URLs, Text and Files. If there's no input: Continue.
    2. If Shortcut Input does not have any value
      1. Get Latest Screenshots — 1
      2. Set Variable Input to Latest Screenshots
      Otherwise
      1. Set Variable Input to Shortcut Input
      End If
    3. Get File from Folder — folder Shortcuts, path Needed Vault/Grab & Go.txt. Set Variable Grab to it.
    4. If Grab is off
      1. Get File from Folder — Shortcuts, Needed Vault/Projects.txt
      2. Split Text by New Lines
      3. Choose from List — prompt Which project?
      4. Set Variable Project to Chosen Item
      5. Ask for Input — Text, Tags? e.g. #night #car (leave it blank if none). Set Variable Tags to it.
      Otherwise
      1. Set Variable Project to Grab
      End If
    5. Get URLs from Input
    6. If URLs has any value
      1. Append to Text File — Input Tags, folder Shortcuts, path Needed Vault/Project/Links.txt, Make New Line on.
      Otherwise
      1. Repeat with Each item in Input
        1. Set Name of Repeat Item to Repeat Item › Name Tags — Don't Include File Extension on.
        2. Save File — Ask Where to Save off, Shortcuts, path Needed Vault/Project/Inbox/, Overwrite off.
        End Repeat
      End If
    7. Show Notification Saved to Project, then Stop and Output Project.

    The “Grab & Go” Shortcut

    Another new Shortcut, named exactly Grab & Go. It switches Grab & Go on (asking which project) and off.

    Show every action
    1. Get File from Folder — Shortcuts, Needed Vault/Grab & Go.txt
    2. If File is off
      1. Get File from Folder — Shortcuts, Needed Vault/Projects.txt
      2. Split Text by New Lines, then Choose from List — Grab & Go into which project?
      3. Text — Chosen Item
      Otherwise
      1. Text — off
      End If
    3. Save File If Result — Ask Where to Save off, Shortcuts, path Needed Vault/Grab & Go.txt, Overwrite If File Exists on.
    4. Show Notification Grab & Go: If Result, then Stop and Output If Result.

    One press, and this page

    1. Side button: Settings › Action Button › Shortcut › Grab & Go.
    2. Or the back of the phone: Settings › Accessibility › Touch › Back Tap › Double Tap › Grab & Go. Triple Tap › Save to Needed Vault saves your latest screenshot.
    3. From anywhere: Share › Save to Needed Vault — screenshots, Photos, Safari, Instagram, YouTube.
    4. This page on your Home Screen: in Safari, Share › Add to Home Screen. It opens like an app, and works offline.

    Grab & Go on your phone is only your phone's — the Mac keeps its own. Taking something out of Needed Vault on your phone puts it in the Mac's Trash on the next Sync, never gone for good. Links and screenshots wait on your phone until you're back online.
